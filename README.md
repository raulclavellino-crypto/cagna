# Cagna Junín

App de gestión interna para productos, ventas, pedidos, clientes, stock y catálogo de WhatsApp.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abrir la URL que indique Vite, normalmente `http://127.0.0.1:5173`.

## Qué incluye

- React + Vite.
- Datos mock locales.
- Productos con alta, edición, eliminación, foto con preview local y filtros por categoría.
- Registro de ventas con descuento automático de stock.
- Control de stock con ingresos, salidas y ajustes.
- Gestión de pedidos y clientes.
- Catálogo seleccionable con link para compartir por WhatsApp.
- Reportes simples de ventas, inventario, stock bajo y categorías.

La estructura queda preparada para reemplazar los datos locales por Supabase, Firebase o una API propia.
